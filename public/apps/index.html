Apps

Each link opens a small app in this browser tab. You give it files and it gives you the result. Your files stay on this computer: the app runs a program in the tab, and nothing is uploaded. The first time, the app fetches the program it needs, which takes a few seconds.

Make your own

An app is one small file. This one is the whole of "Make scans searchable":

{ "name": "Make scans searchable", "accept": [".png", ".jpg"], "run": "tesseract {in} stdout pdf", "needs": ["tesseract-ocr"] }

Put the file in a GitHub repository or a gist as app.json, or write its keys after the # of the address. Try it on the link page. The format is in docs/APPS.md.

Each person who opens a link gets their own copy of the app and their own data. Nothing is shared between them.
