A link is a computer

Write commands, or a small app, after the # of the address. The link opens a computer in a browser tab. The computer shows the person what the link will run, and runs it when they choose Run. A browser never sends the part after the # to a server. tabcomputer

Open

How the address is read

  • The part after the # is an app when it starts with a key of an app and =, such as name=, run= or table=.
  • Anything else is commands. #sh: in front makes it commands whatever follows.
  • #gist:ID opens a gist. A gist with an app.json is an app. Any other gist runs its first script.
  • A space typed by hand works. A new line is %0A.

An app in the box is one key on each line. The address joins the lines with &.

KeyWhat it says
name, aboutWhat the app is called, and what it does.
runThe command. {in} is each file a person gives it. {field} is what a field holds.
accept, outThe kinds of file it takes (.png,.jpg), and what a result is called ({name}.pdf).
field.NAMEA field and its label. field.NAME.type, .value and .choices say more about it.
stdin, live, shellWhat the command reads, whether it runs as the person types, and whether it is a shell line.
table, columnsA table kept in a file: columns=Date:date,What,Amount:number.
needsDebian packages the app installs before its first start.

The full list is in docs/APPS.md.

What happens when a link is opened

tabcomputer takes the link out of the address first. Then tabcomputer shows the commands, or what the app runs and installs, in a window with Cancel and Run. Nothing runs before the person chooses Run or Install. A link opened inside another page's frame is ignored.

A link holds text only, and at most 48,000 characters. In a tabcomputer terminal, link writes a link from what was done there.
