Your own project

Put a setup script at .tabcomputer/run.sh in a GitHub repository and link to https://tabcomputer.com/?run=gh:owner/repo. tabcomputer shows the person the whole script and runs it only when they choose Run.

A badge for a README: [![Run in tabcomputer](https://tabcomputer.com/recipes/badge.svg)](https://tabcomputer.com/?run=gh:owner/repo)

The format, the arguments a link can carry and the trust rules are in docs/RUN_LINKS.md.
